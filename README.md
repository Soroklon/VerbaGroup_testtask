# Wildberries Parser

Парсер товаров Wildberries по поисковому запросу. Результат — два XLSX-файла в директории `result/`.

## Результаты

| Файл                 | Содержимое                            |
|----------------------|---------------------------------------|
| result/catalog.xlsx  | Все спарсенные товары                 |
| result/filtered.xlsx | Выборка по фильтрам из config.txt     |

## Параметры (config.txt)

| Параметр   | По умолчанию                 | Описание                                       |
|------------|------------------------------|------------------------------------------------|
| query      | пальто из натуральной шерсти | Поисковый запрос                               |
| limit      | 10                           | Количество товаров. 0 — парсить всё            |
| min_rating | 4.5                          | Минимальный рейтинг для filtered.xlsx          |
| max_price  | 10000                        | Максимальная цена для filtered.xlsx            |
| country    | Россия                       | Страна производства для filtered.xlsx          |

## Установка и запуск

```bash
chmod +x run.sh && bash run.sh
```

## Требования

- Python 3.9+
